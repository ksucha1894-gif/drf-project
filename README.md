# Онлайн-платформа обучения (LMS) в Docker

Проект упакован в Docker контейнеры с помощью Docker Compose для быстрой оркестрации и запуска всех зависимостей одной командой.

## Требования
- Docker
- Docker Compose

## Быстрый запуск

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Создайте файл `.env` в корневой директории и заполните его согласно шаблону (укажите свои пароли и SECRET_KEY).
3. Запустите проект в фоновом режиме:
   ```bash
   docker-compose up -d
   ```

4. Примените миграции базы данных внутри контейнера:
   ```bash
   docker-compose exec web python manage.py migrate
   ```

5. Создайте суперпользователя (администратора):
   ```bash
   docker-compose exec web python manage.py createsuperuser
   ```

Приложение будет доступно по адресу: http://127.0.0

## Остановка проекта
Чтобы остановить все контейнеры с сохранением данных в томах (volumes), выполните:
```bash
docker-compose down
```

## Деплой проекта
Приложение успешно развернуто на удаленном сервере облачного хостинга.
Реальная ссылка на работающий сервер для проверки: http://amvera.media
Доступные порты приложения: 80, 443 (Внешний порт 8000 закрыт для безопасности с помощью реверс-прокси Nginx).
Проект контейнеризирован и работает через связку Nginx (Reverse Proxy) + Gunicorn + Celery + PostgreSQL.
