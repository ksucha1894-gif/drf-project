# 🎓 Онлайн-платформа обучения (LMS) в Docker & Amvera Cloud

Проект представляет собой коммерческую API-платформу самообразования, контейнеризированную с помощью Docker Compose для быстрой оркестрации и запуска всех портов системы одной командой.

## 🔗 Реальная ссылка на развернутое приложение
Проект успешно развернут на удаленном сервере облачного хостинга:
**[https://amvera.media](https://amvera.media)**

## 🛡️ Описание переменных окружения (.env)
Для успешного запуска системы в корневой директории должен быть создан файл `.env` со следующими параметрами:
- `SECRET_KEY` — Уникальный криптографический ключ безопасности Django.
- `DEBUG` — Статус отладки системы (False для продакшена).
- `ALLOWED_HOSTS` — Список разрешенных хостов (включая localhost и домен Amvera).
- `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD`, `DATABASE_HOST`, `DATABASE_PORT` — Параметры подключения СУБД PostgreSQL.
- `STRIPE_SECRET_KEY` — Секретный токен интеграции платежного шлюза Stripe.
- `CELERY_BROKER_URL`, `CELERY_RESULT_BACKEND` — Порты подключения Redis для фоновых задач.

## 🗺️ Основные API-маршруты приложения
### 📚 Курсы и Уроки (LMS)
- `GET /lms/courses/` — Вывод списка всех доступных курсов (Доступно IsAuthenticated/IsModer).
- `POST /lms/courses/` — Создание нового курса (Запрещено модераторам).
- `POST /lms/courses/<id>/payment/` — Генерация внешней ссылки на оплату курса через Stripe API.
- `POST /lms/lessons/create/` — Создание нового урока.
- `GET /lms/lessons/` — Вывод списка всех уроков.

### 👤 Пользователи и Авторизация
- `POST /users/token/` — Получение JWT-токена доступа (SimpleJWT).
- `POST /users/token/refresh/` — Обновление JWT-токена.

## 🚀 Инструкция по деплою в Amvera Cloud
Проект поддерживает автоматический CI/CD конвейер:
1. Деплой осуществляется автоматически через **GitHub Actions** при каждом пуше в ветку `develop`.
2. Конвейер запускает проверку кода линтером `Flake8` и прогоняет тесты. При успешном прохождении пайплайна код автоматически собирается в облаке Amvera Cloud.
3. Все миграции базы данных PostgreSQL, сборка статики `collectstatic` и старт сервера `Gunicorn` инкапсулированы внутри Docker-контейнера через автоматический шлюз `entrypoint.sh`.

## 💻 Быстрый локальный запуск

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Создайте файл `.env` в корневой директории и заполните его согласно описанию выше.
3. Запустите проект в фоновом режиме:
   ```bash
   docker-compose up -d --build
   ```

## 🛑 Остановка проекта
Чтобы остановить все контейнеры с сохранением данных в томах (volumes), выполните:
```bash
docker-compose down
```
